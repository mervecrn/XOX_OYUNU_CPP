# XOX_OYUNU_CPP
Bu proje, C++ kullanılarak hazırlanmış basit bir Tic Tac Toe (XOX) oyunudur.
Özellikler : 3x3 oyun tahtası 
             İki oyunculu mod (X ve O)
             Hamle kontrol sistemi
             Kazanın tespit edilmesi
             Konsol tabanlı arayüz
Kullanılan Teknoloji : C++
Amaç : Temel kontrol yapılarıyla oyun geliştirmeyi göstermek.
